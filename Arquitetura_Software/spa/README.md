# Exemplo de Single Page Application

##### Créditos
Os exemplos de código presentes neste repositório foram adaptados do material didático do livro Engenharia de Software Moderna de Marco Tulio Valente, disponível em:

Livro: https://engsoftmoderna.info
Repositório original: https://github.com/mtov/ESM-ExemplosCodigo/tree/master/cap7

Um pequeno exemplo de Single Page Application, usando o framework Vue.js (Seção 7.3). 

O objetivo é apenas ilustrar, de forma mínima, uma aplicação Web com interface (visão + controle) e modelo.

Para visualizar, faça o download do arquivo [index.html](./index.html) para sua máquina local e depois abra-o em um browser.

Você pode também estudar o código desse arquivo, que inclui HTML e JavaScript.
